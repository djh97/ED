# Benchmark Files

This folder documents the semi-synthetic ED benchmark used by the public code release.

The benchmark scenarios are generated by `app.agentic_system.build_evaluation_scenarios()` and used by the evaluation scripts. The scenarios include input payloads, expected operational action labels, and urgent escalation targets. The labels are rule-derived silver-standard operational labels for reproducible pre-clinical evaluation.

Generated evaluation outputs are intentionally excluded from the repository. Re-run the evaluation scripts to reproduce results.
